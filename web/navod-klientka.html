Návod krok za krokem

Holubník z počítače

Claude Code, Zara a tvůj tým holoubků v jednom okně terminálu. Telegram nikam nemizí, tohle je práce s pořádnou klávesnicí.

Čas
45 min na Macu, hodina na Windows
Předpoklad
Předplatné Claude Pro nebo Max
Znalosti
Žádné, příkazy jen kopíruješ

1Než začneš

Tři věci, které si instaluješ, a co každá dělá.

CoK čemu to je
Claude CodeClaude přímo v počítači. Vidí tvoje soubory, umí je psát a upravovat.
ZaraMozek nad Claude Code: paměť, dovednosti, tvoje wiki, tvůj styl psaní.
Propojení na holubníkPříkaz holubnik, kterým zadáváš práci Rozárce a celému týmu.

Co si nachystej

  • Předplatné Claude Pro nebo Max na claude.ai. Free plán Claude Code neumí.
  • Balíček „zara-start". Pozvánku do repozitáře nebo ZIP dostaneš ode mě.
  • Údaje k holubníku: adresa serveru a přihlášení. Pošlu ti je zvlášť.
  • Systém: macOS 13 a výš, nebo Windows 10 (verze 1809) a výš, 4 GB RAM.
Klid v duši

Holubník ti běží na vlastním serveru a běží dál. Nic z toho, co teď instaluješ, ho nenahrazuje ani nepřesouvá. Instaluješ si jenom ovladač, tedy okno, kterým do něj mluvíš.

2Instalace

Vyber si svůj systém, návod se přepne. Vždycky, když uvidíš tmavý rámeček, zkopíruj jeho obsah do terminálu a dej Enter.

2.1Otevři Terminál

Stiskni ⌘ + mezerník, napiš Terminál, potvrď Enterem.

2.2Nainstaluj Claude Code

curl -fsSL https://claude.ai/install.sh | bash

Až to doběhne, zavři okno terminálu a otevři nové. Jinak počítač příkaz claude ještě nezná. Pak ověř:

claude --version

Musí vypsat číslo verze. Když píše command not found:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

2.3Přihlas se

claude

Otevře se prohlížeč, přihlas se svým účtem Claude. Pak v okně Clauda napiš /exit.

2.4Stáhni balíček Zara

git clone https://github.com/3orisky/zara-start.git ~/zara-start

Když ti napíše, že git nezná, spusť xcode-select --install, počkej pár minut, až se doinstalují vývojářské nástroje, a příkaz zopakuj. Když jsi dostala ZIP, rozbal ho a přesuň složku tak, aby cesta byla ~/zara-start.

2.5Nainstaluj Zaru

cd ~/zara-start
bash install.sh

Instalátor ověří Claude Code a Bun (Bun ti nabídne doinstalovat, odpověz a), zeptá se, jak ti má Zara říkat, zazálohuje cokoliv, co už v ~/.claude máš, a nakopíruje mozek, paměť a wiki. Trvá to zhruba minutu.

Potom zavři terminál a otevři nový.

Jedno okno navíc

Zara je psaná pro linuxové prostředí, takže na Windows pojede uvnitř WSL 2. Není to virtuál, který by ses musela učit. Je to jenom další okno terminálu, které se chová jako Mac.

2.1Zapni WSL 2

Start → napiš PowerShell → klikni pravým na Windows PowerShell → Spustit jako správce. Do okna napiš:

wsl --install

Nainstaluje se Ubuntu. Restartuj počítač. Po restartu se Ubuntu samo otevře a zeptá se na uživatelské jméno (malá písmena bez diakritiky) a heslo. Heslo se při psaní nezobrazuje ani hvězdičkami, to je normální. Zapamatuj si ho, budeš ho potřebovat u příkazů se sudo.

Když wsl --install skončí chybou, zapni ve funkcích Windows položky „Platforma virtuálního počítače" a „Podsystém Windows pro Linux", restartuj a příkaz zopakuj.

Od téhle chvíle

Všechno další píšeš do okna Ubuntu (najdeš ho v nabídce Start), ne do PowerShellu.

2.2Připrav Ubuntu

sudo apt update && sudo apt install -y curl git unzip

Vyžádá si heslo z předchozího kroku.

2.3Nainstaluj Claude Code

curl -fsSL https://claude.ai/install.sh | bash

Zavři okno Ubuntu, otevři nové a ověř:

claude --version

Když píše command not found:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

2.4Přihlas se

claude

Otevře se prohlížeč ve Windows, přihlas se účtem Claude. Pak napiš /exit.

2.5Nainstaluj Zaru

git clone https://github.com/3orisky/zara-start.git ~/zara-start
cd ~/zara-start
bash install.sh

Instalátor napíše varování, že je psaný pro macOS. To je v pořádku, v Ubuntu doběhne. Odpověz a na doinstalování Bunu a zadej svoje jméno. Potom zavři okno Ubuntu a otevři nové.

2.6Kde mám svoje soubory

Ubuntu má vlastní domovskou složku. K dokumentům z Windows se dostaneš přes:

cd /mnt/c/Users/<TvojeWindowsJmeno>/Documents

A naopak, do složek Ubuntu se dostaneš z Průzkumníka souborů: do adresního řádku napiš \\wsl$\Ubuntu\home\<tvoje-jmeno>. Pracovní soubory pro Zaru ale drž radši v Ubuntu (~/Projects/...), je to výrazně rychlejší.

3První rozhovor se Zarou

V terminálu napiš claude a pak Zaře tohle:

Přečti si skills/PAI/SKILL.md a doptej se mě, kdo jsem.
Vyplň si můj profil.

Zara se tě postupně zeptá, čím se živíš, jak s tebou má mluvit a co má vědět o tvé práci. Odpovědi si uloží. Kdykoliv později můžeš říct „aktualizuj si můj profil".

Ověř, že jí funguje paměť

Napiš „zapamatuj si, že moje hlavní cílovka jsou …", zavři okno, otevři nové a zeptej se „co víš o mojí cílovce?". Když odpoví, je hotovo.

Naplň wiki

Nepovinné, ale vyplatí se. ~/business-wiki/ je znalostní báze o tvém podnikání: produkty, ceny, procesy, čísla. Zara si ji čte, kdykoliv řešíš byznys, a přestane hádat. Hoď do ~/business-wiki/raw/ cokoliv, co máš (ceník, export z fakturace, popisy produktů) a řekni: „Zpracuj raw/<soubor> do wiki podle WIKI.md."

4Propojení na holubník

Holubník má vlastní API, přes které s ním mluví Telegram i nástěnka. Stejným API ho budeš ovládat z počítače příkazem holubnik.

holubnik "napiš newsletter o migrénách"   # úkol pro Rozárku
holubnik tasks                            # nástěnka úkolů
holubnik usage                            # kolik se utratilo (tokeny / Kč)
holubnik agents                           # stav holoubků
holubnik memory rozarka                   # co si který holoubek pamatuje
holubnik health                           # žije to?
holubnik restart                          # restart (jen na serveru)
Dvě oddělené peněženky

Příkaz holubnik běží přes API klíč tvého holubníku, takže se objeví ve vyúčtování Anthropicu stejně jako práce holoubků. Naopak claude v terminálu (Zara) jede z tvého předplatného Pro nebo Max. Nepletou se.

Vyber si jednu ze dvou cest.

Přes serverDoporučeno na začátek

Nic se nenastavuje a nic se nevystavuje do internetu. Příkaz je na serveru už nainstalovaný a přístup si najde sám.

ssh uzivatel@adresa-tvojeho-serveru
holubnik "napiš newsletter o migrénách"

Přihlašovací údaje dostaneš ode mě. Když se poprvé ptá Are you sure you want to continue connecting?, napiš yes. Odhlášení ze serveru: exit.

Ať to nemusíš psát pokaždé celé, ulož si zkratku (na Windows místo ~/.zshrc piš ~/.bashrc):

echo 'alias holubnik-ssh="ssh -t uzivatel@adresa-serveru holubnik"' >> ~/.zshrc

V novém okně pak stačí holubnik-ssh "co je dneska na nástěnce?".

Přímo ze svého počítačePohodlnější

Tuhle cestu ti musím jednorázově zapnout na serveru (zabezpečená brána s tokenem). Dostaneš ode mě adresu API, token a soubor holubnik.ts.

1. Bun (když jsi instalovala Zaru, už ho máš):

curl -fsSL https://bun.sh/install | bash

2. Ulož holubnik.ts do složky ~/bin/ a udělej z něj příkaz:

mkdir -p ~/bin
printf '#!/usr/bin/env bash\nexec bun ~/bin/holubnik.ts "$@"\n' > ~/bin/holubnik
chmod +x ~/bin/holubnik
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.zshrc

3. Nastav adresu a token:

echo 'export HOLUBNIK_URL="https://api.tvuj-holubnik.cz/api"' >> ~/.zshrc
echo 'export HOLUBNIK_TOKEN="token-ktery-dostaneš"' >> ~/.zshrc
source ~/.zshrc

4. Ověř:

holubnik health
holubnik "ahoj, ozvi se"

Na Windows všude zaměň ~/.zshrc za ~/.bashrc.

Ať to za tebe dělá Zara

Nemusíš si pamatovat žádné příkazy. Řekni Zaře v okně claude, ať si do ~/.claude/CLAUDE.md přidá tenhle blok:

## Holubník
Můj tým AI agentů (holubník) běží na vlastním serveru a ovládá se
příkazem `holubnik` v terminálu. Když ti řeknu něco, co má udělat
holubník (napiš newsletter, co je na nástěnce, kolik jsme utratili,
co dělá který holoubek), použij:
  holubnik "<příkaz přirozenou řečí>"   - úkol pro Rozárku
  holubnik tasks | usage | agents | health | memory <holoubek>
Než pošleš úkol, ukaž mi znění příkazu a počkej na moje ano.
Pozor: tyhle příkazy se účtují z API klíče holubníku,
ne z mého předplatného.

Od té chvíle stačí Zaře napsat „zeptej se holubníku, co je na nástěnce". Ona to spustí, výstup přeloží do lidské řeči a může na něj rovnou navázat, třeba text upravit a poslat zpátky.

Telegram nikam nemizí. Ovládání z počítače je navíc, ne místo něj. Karty ke schvalování, hlasovky a rychlé ano/ne jsou v Telegramu dál pohodlnější. Počítač je na dlouhá zadání, práci s texty a na chvíle, kdy chceš vidět víc než jednu obrazovku.

Skilly Zary se nespouští samy. Zara ti napíše „pro tohle by se hodily skilly X, Y, použít?" a čeká na tvoje ano.

6Když se něco pokazí

ProblémŘešení
claude: command not foundZavři a otevři nové okno terminálu. Pořád nic → přidej export PATH="$HOME/.local/bin:$PATH" do ~/.zshrc (Mac) nebo ~/.bashrc (Windows).
bun: command not foundcurl -fsSL https://bun.sh/install | bash, pak nové okno.
Zara se hned po instalaci chová divněZavři všechna okna terminálu a otevři nové. Její doplňky se načítají při startu.
Chci zpátky stav před instalacíZáloha je v ~/.claude-zaloha-<datum>. Smaž ~/.claude a zálohu přejmenuj zpátky.
403 u příkazu holubnikToken nesedí. Napiš mi, zkontrolujeme ho.
Nepřipojím se k holubníkuŠpatná adresa, nebo neběží služba. Zkus to přes Telegram, a když neodpovídá ani tam, napiš mi.
Windows: wsl --install hlásí chybuZapni ve funkcích Windows „Platforma virtuálního počítače" a „Podsystém Windows pro Linux", restartuj.

7Bezpečnostní minimum

  • Klíče a tokeny nikdy nepiš do souborů projektu. Patří do ~/.zshrc nebo ~/.bashrc, případně do .env, který je v .gitignore.
  • HOLUBNIK_TOKEN má stejnou sílu jako klíč od celého holubníku. Když unikne, napiš mi, výměna je otázka minuty.
  • Do paměti Zary ani do wiki nepiš hesla, čísla účtů a rodná čísla.
  • Zara se u nebezpečných příkazů ptá „opravdu?". Čti to, odpovědnost je pořád tvoje.
  • Když počítač ztratíš nebo prodáváš: smaž ~/.claude, ~/zara-start a řádky s tokeny z ~/.zshrc nebo ~/.bashrc, a řekni mi, ať vyměním token.
Zasekneš se kdekoliv? Zkopíruj celou chybu a pošli mi ji. Většina zádrhelů má opravu na jeden řádek.
